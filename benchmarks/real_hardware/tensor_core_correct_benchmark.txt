=== WMMA API Reference (learned the hard way) ===
fragment<accumulator,16,16,16,float>.num_elements = 8
cf.x[0] on lane 0 = C[0][0] = Σ(a[i]*b[i]) for 16-element vectors
load_matrix_sync(af, ptr, 16) with row_major: fills first ROW
load_matrix_sync(bf, ptr, 16) with col_major: fills first COLUMN
mma_sync produces C=A*B where C[0][0] = dot(a[0:16], b[0:16])
MUST load both A and B per chunk if iterating over input chunks!
